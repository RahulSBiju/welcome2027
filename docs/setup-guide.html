✉️ Part 1: Email (about 10 min)

Supabase's built-in sender only manages a few emails an hour, so we send through your Gmail instead. It's free and handles about 500 a day. Resend wasn't used because its free plan only emails your own address.

1. Create a Gmail “app password”

A separate 16-character password just for Supabase. Your real Gmail password is never shared.

  1. Open myaccount.google.com/security and turn on 2-Step Verification if it's off (Google requires it).
  2. Open myaccount.google.com/apppasswords.
  3. App name: Welcome 2027 → Create.
  4. Copy the 16-character password it shows (keep the tab open for the next step).

2. Send Supabase emails through Gmail

Go to Authentication → Emails → SMTP Settings → turn on Enable custom SMTP:

Sender emailyour Gmail address
Sender nameWelcome 2027
Hostsmtp.gmail.com
Port465
Usernameyour Gmail address
Passwordthe 16-character app password from step 1

Click Save. Then Authentication → Rate Limits → Emails per hour = 30 → Save.

3. Put the code in the emails

The app asks people to type a code from the email. Go to Authentication → Emails → Templates.

“Confirm signup” template: replace the subject and body with:

Subject
Your Welcome 2027 code: {{ .Token }}
Body
<h2>Welcome to the trip planning! 🌴</h2>
<p>Enter this code in the app to confirm your email:</p>
<p style="font-size:28px;font-weight:bold;letter-spacing:6px">{{ .Token }}</p>
<p>If you didn't sign up, you can ignore this email.</p>

“Reset password” template:

Subject
Your Welcome 2027 password reset code: {{ .Token }}
Body
<h2>Reset your password 🔑</h2>
<p>Enter this code in the app to set a new password:</p>
<p style="font-size:28px;font-weight:bold;letter-spacing:6px">{{ .Token }}</p>
<p>If you didn't ask for this, you can ignore this email. Your password won't change.</p>

Click Save on each template.

4. Set the Site URL

Authentication → URL Configuration → Site URL:

https://yearend-trip.expo.app

Save.

5. Turn email confirmation back on

Authentication → Sign In / Providers → Email → turn Confirm email ON → Save.

New friends will then get a code after signing up. Existing accounts aren't affected.

6. Test it

  1. Open the app (signed out) → Forgot password? → enter your email → Send reset code.
  2. The email should arrive within a minute. The first time, check Spam and mark it “Not spam”.
  3. Enter the code and a new password, and you're signed in. ✅

🔔 Part 2: Push notifications (about 15 min)

The app side and the database are ready. This part sets up the small server function that actually sends the notifications.

1. Deploy the “send-push” Edge Function

  1. Supabase → Edge Functions → Deploy a new function → Via Editor.
  2. Function name: send-push (exactly this).
  3. Delete the sample code and paste in the whole file vacation-planner\supabase\functions\send-push\index.ts. To open it, right-click the file → Open with → Notepad → Ctrl+A, Ctrl+C.
  4. Click Deploy function.
  5. Open the function's Details/Settings, turn OFF “Verify JWT” (it may say “Enforce JWT verification”), and save.
Turning off JWT is safe here. The database calls the function with its own secret (steps 2–3), and any other caller is rejected.

2. Add the function's 4 secrets

Supabase → Edge Functions → Secrets → add each name + value:

VAPID_PUBLIC_KEY this public key:
BNJ8zxdZOSASqdyfl2wSficLaGjiDKic_TW_iZuTfb3TUNTx5C7FkFoH-EziUPpdm23pWiAY358Z2kVKmHSqpA0
VAPID_PRIVATE_KEY open vacation-planner\push-keys.local.txt with Notepad and copy the value after VAPID_PRIVATE_KEY=. 🔒 Keep it private: it isn't in this page or on GitHub.
VAPID_SUBJECT mailto: followed by your email, e.g. mailto:you@gmail.com
PUSH_WEBHOOK_SECRET a long random password. Make one here: 
(generating…)
You'll paste the same value again in step 3. It was made in your browser and isn't saved anywhere.

SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY are provided automatically; don't add them.

3. Give the database the same secret

Supabase → SQL Editor → New query → paste this (it already contains the secret generated above) → Run:

select vault.create_secret('(generating…)', 'push_webhook_secret');
⚠️ If you reload this page, a new secret is generated. Make sure steps 2 and 3 use the same value. If they ever end up different, run this with the value you saved in step 2:
select vault.update_secret((select id from vault.secrets where name = 'push_webhook_secret'), 'YOUR-SECRET');

4. Turn on notifications on your phone

  • Android: open the app in Chrome → My Trips → 🔔 Turn on notifications → Allow.
  • iPhone (iOS 16.4+): open it in Safari → Share → Add to Home Screen → open the app from the home-screen icon → 🔔 Turn on notifications → Allow. Apple only allows notifications for Home Screen apps.

5. Test it

  1. On your laptop, sign in as the test account (e.g. an Incognito window).
  2. Post a message in your trip's 💬 Group chat.
  3. Your phone should buzz within a few seconds: “💬 test in Group chat: …” 🎉

Nothing arrived?

  • Supabase → Edge Functions → send-push → Logs. A 401 means the secrets in steps 2 and 3 don't match.
  • SQL Editor: select * from net._http_response order by created desc limit 5; shows the database's recent calls.
  • Check the phone allows notifications for Chrome or the app in its settings.
